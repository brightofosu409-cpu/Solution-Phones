SOLUTION PHONES
About the Project
SOLUTION PHONES is a cross-platform mobile e-commerce application designed to help customers browse mobile phones,view prices, add products to cart, and place orders.
This project is being developed using Flutter and Dart for Andriod and IOS.

Current Features

Browse available mobile phones.
View phone names and prices.
Add products to the shopping cart.
Review items in the cart.
Proceed to checkout.
Place orders and receive order confirmation.

Technology Used
Flutter 
Dart
Visual Studio Code
Git and GitHub

Project Goals

The goal is to build a simple,user-friendly mobile shopping experience for customers of SOLUTION PHONES.
